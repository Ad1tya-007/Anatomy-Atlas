# 0004. Append-only review log, replayed locally

## Context

FSRS cards are a projection of every grade the learner has given. Two devices, or a browser that already has local reviews plus a newly signed-in account, must converge without a last-write-wins clobber.

## Decision

Treat **reviews as an append-only log**. Each event has a UUID. IndexedDB stores `{ ...event, synced: 0 | 1 }`. The outbox is `synced = 0`.

On sync, unsynced rows POST to Supabase; the response is the server's events the client does not have yet. `repository.add` ignores duplicate ids. The in-memory FSRS map is `replay(scheduler, events)`.

Saved camera views are a separate table, not mixed into the review log.

## Why not "upsert the card"

A card row `{stability, difficulty, due}` is a lossy fold. Merging two devices would need custom conflict rules and would drop the history the progress dashboard charts. The log is small (one JSON object per answered question).

## Status

Accepted.
